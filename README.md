# Rondkijken

360°-rondkijktour door de begane grond met het kleurplan: woonkamer, eetzone, keuken, speelkamer en hal.

- Panorama's: gerenderd in Blender (Cycles, equirectangular 4096 × 2048).
- Viewer: [Pannellum](https://pannellum.org/) 2.5.6 via jsDelivr.
- Kleuren en materialen zijn benaderingen.

Live: https://gmschouten.github.io/rondkijken/
